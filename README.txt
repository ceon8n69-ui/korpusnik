КОРПУСНИК — приложение для iPhone (PWA)

1) Залейте ВСЕ файлы этой папки на любой https-хостинг:
   • Netlify Drop: app.netlify.com/drop — перетащите папку, получите ссылку.
   • или GitHub Pages: новый репозиторий → загрузить файлы → Settings → Pages → Branch: main.
2) На iPhone откройте ссылку в Safari.
3) Кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
4) Запускайте с иконки: на весь экран, без адресной строки.
   После первого открытия работает без интернета.

Заказы и цены хранятся на телефоне. Делайте «Экспорт заказов» для резервной копии.
